The Isolated Replica

  • DifficultyBeginner
  • Time3-5 minutes

You are troubleshooting a distributed service.

Three replicas store the same value. A network issue isolates one replica. Moments later, a write occurs. A customer reads from the isolated node. Will they see the latest value?

    Why?

    Replica A acknowledged the write immediately, even though B and C had not applied it. The A-to-C message was dropped at the blocked link and was not retried. C still held 0, so the customer read the old value despite A acknowledging 1.

    Key lesson

    An acknowledgement does not mean every replica has applied the write.

    This result follows only from this exercise's rules. Other systems may reject or block a read, or use different replication behavior.
